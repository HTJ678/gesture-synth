# Gesture Synth v1 — 设计文档

- **日期**：2026-10-04
- **状态**：已确认（小侯 2026-10-04 15:14 同意，并砍掉滑音）

## 目标

复刻"手势 → 音阶"的浏览器小乐器，作为**个人作品墙**（GitHub / 个人站）的一件作品；同时自己玩着要有意思。

**成功标准**：陌生人打开页面 30 秒内"哦"一声 —— 随便动两下就能出能听的音，不需要懂音乐。

## 已确认的取舍

| 决定 | 结果 |
| --- | --- |
| 功能范围 | **只做音阶**。滑音、和弦、节拍手势全部砍到 v2 |
| 代码谁写 | 小爪写（方案 A），小侯负责玩与挑刺 |
| 映射 | 手指数量 → 音阶级数；手的高度 → 八度；左右 → 音量 |
| 音阶 | 大调五声（C D E G A），保证"怎么伸都不难听" |
| 平台 | 纯静态单页，GitHub Pages 托管 |

## 架构

```
摄像头 → MediaPipe HandLandmarker（21 关键点）
       → logic.mjs（数手指 / 音阶映射 / EMA 平滑 / 去抖）
       → Web Audio 振荡器（triangle + sub sine + lowpass）
```

- 技术栈：原生 ESM + Web Audio + `@mediapipe/tasks-vision@1.0.1`（jsDelivr CDN）
- 无构建、无框架、无服务器；GitHub Pages 直接托管（顺带满足摄像头所需的 HTTPS）
- 模型文件自带（`models/hand_landmarker.task`），不依赖 Google CDN
- `logic.mjs` 与 DOM / 音频完全解耦 → 可用 `node --test` 单元测试

## 关键设计点

1. **抗抖动分两层**：数值层 EMA（音量、关键点），状态层 `Stabilizer` 去抖（手指数量 140ms、八度 260ms）。没有这层，手一抖就"哒哒哒"乱跳音。
2. **换音用 12ms 斜坡**，不是滑音：避免"咔"声，但音仍然是离散跳变（小侯明确要的）。
3. **拇指是启发式的**：用"拇指尖到手腕的距离 > 拇指根到手腕距离 × 1.05"判定。不可靠时界面上有"含拇指"开关，关掉只用四指。
4. **方向无关的伸指判定**：用"指尖到手腕的距离 > 指中关到手腕的距离"，比"指尖在关节点上方"更抗手部旋转。
5. **三段自检灯**（音频 / 模型 / 摄像头），让"为什么没声音"一眼可查。

## 已知限制

- 弱光 / 逆光下关键点会飘
- 单手（`numHands: 1`）
- 必须 `localhost` 或 HTTPS
- CDN 不通时加载失败（模型已本地化，但 wasm/JS 仍走 jsDelivr）
